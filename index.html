Introduction

Overview of the DBMS Project

The Event Equipment Management System is a database solution designed to manage events and track equipment efficiently. The system stores and manages event information, suppliers, staff records, equipment availability, and maintenance history.


This project was developed using MySQL Workbench and follows normalization principles to eliminate redundancy and improve database performance.

Database Design

Structure and relational database design

Primary Keys

Each table contains a unique identifier such as event_id, equipment_id, and staff_id.

Foreign Keys

Relationships are maintained using foreign keys to ensure referential integrity.

Normalization

The database is normalized to 3NF to eliminate redundancy.

Optimization

JOINs, views, and indexed primary keys improve query performance.
